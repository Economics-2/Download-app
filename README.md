# ভিডিও ডাউনলোডার (Android)

yt-dlp ও ffmpeg অ্যাপের ভেতরেই বান্ডেল করা। ফিচার: ভিডিও/অডিও (MP3) ডাউনলোড, প্লেলিস্ট (সর্বোচ্চ ৫০টি, জিপে), সাবটাইটেল (.srt), ডাউনলোড ইতিহাস, yt-dlp আপডেট বাটন, স্ক্রিন বন্ধ থাকলেও ডাউনলোড (নোটিফিকেশনসহ)।
ডাউনলোড করা ফাইল ফোনের **Downloads/VideoDownloader** ফোল্ডারে জমা হয়।

## GitHub থেকে APK বানানোর ধাপ (কম্পিউটার বা Android Studio লাগবে না)
1. GitHub-এ নতুন রিপো বানান (যেমন `video-downloader-app`)।
2. এই ফোল্ডারের **সব ফাইল ও ফোল্ডার** (লুকানো `.github` সহ) রিপোর রুটে আপলোড করুন।
   টার্মিনাল থাকলে:
   ```
   git init && git add . && git commit -m "first"
   git branch -M main
   git remote add origin https://github.com/<আপনার-ইউজারনেম>/video-downloader-app.git
   git push -u origin main
   ```
   ওয়েবে আপলোড করলে `.github/workflows/build-apk.yml` ফাইলটি অবশ্যই যেন যায়।
3. রিপোর **Actions** ট্যাবে "Build APK" চলবে (৫–১০ মিনিট)। না চললে Actions থেকে "Run workflow" চাপুন।
4. সবুজ টিক এলে রিপোর **Releases → Latest APK** থেকে `VideoDownloader.apk` ফোনে ডাউনলোড করুন।
   (প্রাইভেট রিপো হলে GitHub-এ লগইন করা অবস্থায় ডাউনলোড করুন।)
5. ফোনে ইনস্টল: "অজানা উৎস থেকে ইনস্টল" অনুমতি দিন। Play Protect সতর্কতা দিলে "তবুও ইনস্টল" বেছে নিন, কারণ অ্যাপটি আপনার নিজের বানানো।

## বিল্ড ব্যর্থ হলে
Actions-এ লাল ক্রসে ক্লিক করে এরর লগ দেখুন এবং শেষ ২০–৩০ লাইন কপি করে আমাকে পাঠান।

## ব্যবহারের টিপস
- ইনস্টলের পর প্রথমবার খুলতে কয়েক সেকেন্ড লাগে (Python ও ffmpeg এক্সট্র্যাক্ট হয়)।
- কোনো সাইট কাজ না করলে অ্যাপের নিচে "yt-dlp আপডেট করুন" চাপুন।
- ব্যাকগ্রাউন্ডে ডাউনলোড চালু রাখতে ফোনের Battery Optimization-এ অ্যাপটিকে "Unrestricted" দিন।
- শুধু আর্ম64 ফোনে চলে (প্রায় সব আধুনিক ফোন)।

## জানা সীমাবদ্ধতা
- এটি debug-সাইন করা APK, ব্যক্তিগত ব্যবহারের জন্য যথেষ্ট। Play Store-এ প্রকাশের উপযোগী নয়।
- শুধু নিজের বা অনুমতিপ্রাপ্ত কনটেন্ট নামান। কপিরাইট ও প্ল্যাটফর্মের নীতি মানা আপনার দায়িত্ব।
